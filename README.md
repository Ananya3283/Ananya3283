## 📂 Featured Projects

### 🛣️ [Ride-Sharing ELT Pipeline and Data Warehouse](https://github.com/Ananya3283/ride-sharing-elt)

[![CI](https://github.com/Ananya3283/ride-sharing-elt/actions/workflows/ci.yml/badge.svg)](https://github.com/Ananya3283/ride-sharing-elt/actions/workflows/ci.yml)

A monthly batch ELT pipeline for NYC Uber and Lyft trip data. It lands raw Parquet in an
S3-compatible lake, cleans and de-duplicates it with PySpark, loads PostgreSQL with an atomic
per-month swap, and models a star schema in dbt guarded by 31 data tests. Airflow orchestrates
it in Docker and GitHub Actions tests every push. Verified on a real run of **2M+ trips**.

**Tech Stack:** Python • PySpark • Airflow • dbt • PostgreSQL • Docker • S3 • GitHub Actions
